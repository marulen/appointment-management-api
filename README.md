# Appointment management API

Backend application for managing clients, professionals, and appointments.

This project is being developed progressively to strengthen Java backend development skills while applying professionl software developmentp practices.

## Project goals

The main goals of this project are to:

* Build a web backend using Java without relying on a full application framework.
* Understand the fundamentals behind HTTP request handling and REST APIs.
* Apply object-oriented design and layered architecture.
* Work with relational database using JDBC.
* Develop automated tests as part of the development process.
* Use Git and GitHub following a professional workflow.
* Containerize application infrastructure with Docker.
* Envolve the application progressively towards Spring Boot.

## Initial domain

The application will initially manage three main concepts:

* Clients
* Professionals
* Appointments

The domain and business rules with evolve as the project grows.

## Technology

Initial development will use:

* Java 21
* Maven
* Git and GitHub
* VS Code

Additional technologies will be introduced incrementally when requiered by the application.

# Development approach

The project follows an iterative development process.

New functionality is developed using feature branches, automated tests, code review, conventional commits, and pull request.
